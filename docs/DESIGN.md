# Meet the Dukes design

The design combines a deep-purple hero, serif display headings, a text wordmark, warm campus imagery, and white content cards. Use the shared color variables and existing components in `css/styles.css` first when adding a view.

| Token | Color | Use |
| --- | --- | --- |
| JMU Purple | #450084 | Header, primary actions, links |
| JMU Gold | #CBB677 | Hero action and decorative accents |
| Light Purple | #DACCE6 | Badges, icons, and supporting accents |
| Light Gold | #F4EFE1 | Demo labels, event dates, and closing section |

The wordmark was created for the prototype. The campus hero and organization photographs are generated illustrations of fictional scenes. Organization photographs are cropped from one generated photo sheet and stored locally as JPEGs. The site uses no official marks or university photography. The Georgia and system sans-serif stacks work offline.

The directory uses three, two, or one column depending on available width. Shared focus indicators, labeled filters, live result counts, and a skip link support keyboard and screen-reader navigation. The profile sections stack on small screens. Intramural opportunities have a distinct category and can link to UREC for current details.
